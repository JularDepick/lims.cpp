## 快速开始

**仅适用于 Windows 平台** (C++11) 。

### 使用预编译版本

- 下载 [Release](https://github.com/JularDepick/lims.cpp/releases) 发布的 `lims.exe` 文件后双击运行即可。

### 从源码构建

```bash
git clone git@github.com:JularDepick/lims.cpp.git
cd lims.cpp
cd src
g++ lims.cpp -o lims.exe -O2 -std=c++11 -s -DNDEBUG
```
